# Terra Z — RPG JLU

Site/dossiê do universo **Terra Z**, uma realidade alternativa inspirada no universo DC, com foco em Vanguard Bay e nos personagens do RPG JLU.

## Estado atual

- Versão exibida pelo site: **v1.3.2**
- Publicação: **GitHub Pages**
- Stack: **HTML + CSS + JavaScript puro**
- Branch publicada: `main`
- Página principal: `index.html`
- Estilos: `terra-z.css`
- Lógica: `terra-z.js`

O projeto permanece intencionalmente simples e sem framework. A prioridade atual é estabilizar e modularizar gradualmente a base existente antes de adicionar uma camada tecnológica mais complexa.
