# Modelo de visibilidade e spoilers

A Fase 8 introduz classificação editorial de conteúdo:

- `public` — informação pública;
- `rumor` — informação conhecida no mundo, mas não confirmada;
- `restricted` — informação para grupos específicos;
- `master` — informação de mestre/spoiler forte.

## Importante: não é segurança

Enquanto o Terra Z for servido integralmente por GitHub Pages, qualquer conteúdo incluído em HTML/JavaScript pode ser encontrado por alguém que inspecione os arquivos públicos.

O modo sem spoilers é uma **camada de experiência**, útil para não revelar informações casualmente durante a navegação. Ele não substitui autenticação nem controle de acesso.

## Segurança real futura

Conteúdo realmente secreto deve:

1. sair do bundle público;
2. ser armazenado em origem privada;
3. ser entregue por uma API autenticada;
4. ser retornado apenas a usuários autorizados.

A infraestrutura prevista na Fase 5 é a base para isso.
