# Retratos de personagens

Os retratos canônicos devem ficar nesta pasta.

Padrão de nome recomendado:

```text
tristan-queen.png
riot.png
mark.png
dinah-lance.png
...
```

O vínculo entre personagem e arquivo fica em `data/character-media.js`.

Enquanto `src` estiver vazio, o site mostra um placeholder com as iniciais do personagem.

## Fonte recomendada

Prioridade:

1. imagem local aprovada para o projeto;
2. imagem externa explicitamente escolhida;
3. placeholder.

Não usar automaticamente a primeira imagem encontrada na DC Wiki/Fandom.
